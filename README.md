A voicemail greeting recorded by a cat, for the [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) bounty on make.fun.

## The greeting

> You've reached Waffles. I knocked your phone off the table, so I can't answer it. Meow after the beep.

102 characters, one line. The joke is the voicemail itself: the cat knocked the phone off the table, which is exactly why it cannot answer it.

## How it works

`main.py` writes the greeting to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), checks it against the bounty gate first — UTF-8, 1 to 120 characters, one line, not blank — then reads the file back and proves it holds exactly the greeting.

Run it:

```sh
python3 main.py
```
